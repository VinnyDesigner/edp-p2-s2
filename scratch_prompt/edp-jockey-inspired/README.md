# Environmental Data Platform - Jockey-inspired React implementation

An independently authored EDP landing page inspired by the visual structure of https://jockey.stuudio.xyz/ . This is not that website's original source code or a pixel-exact clone.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (normally http://localhost:5173).

## Build

```bash
npm run build
```

## Antigravity

Open the project folder inside Antigravity, then paste the instruction file `ANTIGRAVITY_PROMPT.md` into your coding agent. Ask the agent to browse the reference live and visually compare both sites, then iterate.

## Notes

Data and charts are illustrative, not real API data. Font imports load from Google Fonts. Replace demo visualizations and links with your production GIS map services, data catalog, and approved brand assets when ready.
